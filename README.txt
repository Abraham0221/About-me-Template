=========================================================
   ALL ABOUT ME — WEBSITE TEMPLATE
=========================================================

WHAT'S IN THIS FOLDER?

  index.html   The skeleton of your page.       (don't need to edit)
  my-info.js   YOUR name, favorites, and facts.  <-- EDIT THIS ONE!
  style.css    Colors and fonts.                (edit the top box to change colors)
  script.js    Builds the page from your info.  (don't need to edit)
  images/      Put your photo here.


HOW TO MAKE IT YOURS (4 steps)

  1. Open my-info.js in a code editor (VS Code, Notepad, Replit,
     CodePen, etc.).

  2. Change the words between the "quote marks" to your own info.
     Keep the quote marks and the commas!

  3. Save the file.

  4. Double-click index.html to open it in your browser.
     Made a change? Save, then press Refresh in your browser.


ADD YOUR PHOTO

  1. Put a picture in the images folder (for example: me.png).
  2. In my-info.js, change   photo: ""   to   photo: "images/me.png"


CHANGE THE PAGE COLORS

  Open style.css. At the very top there's a box that says
  "EDIT THESE COLORS". Change any color code (like #FFC93C).
